# GMA2e – Begriffe Englisch/Deutsch

Glossar der Kategorien auf den Karten des **GameMaster's Apprentice, Second Edition (Base Deck)**. Grundlage sind die englische Anleitung (*GMA2e Instructions, 2025-05-04*) und die englische sowie die deutsche Print-and-Play-Fassung der Karten (*A4 Paper Version, GMA2e Base, 2025-05-03, Low Ink*).

Die Karte dient als Vorlage für Inhalt und Layout der Inspirationskarte in der Solo RPG Engine.

> Hier stehen nur die **Namen der Kategorien** und feste Begriffslisten. Die Karteninhalte selbst sind © Larcenous Designs, LLC und werden hier nicht abgelegt.

**Legende für die Spalte „Quelle DE“:**
- **Karte**: So steht es auf der deutschen Karte.
- **Vorschlag**: Das Feld hat auf der Karte keine Beschriftung; der deutsche Begriff ist ein Vorschlag für die App.

## Die 14 Felder einer Karte

Nummerierung wie in der Anleitung („The Randomizer Breakdown“).

| Nr. | Englisch (Anleitung) | Deutsch | Quelle DE | Inhalt |
|---|---|---|---|---|
| 1 | Difficulty Generator | Schwierigkeitsgenerator | Vorschlag | Zahl 1–10 mit Glockenkurve (meist 4–7, 1 und 10 unter 1 %) |
| 2 | Likely Odds | Chancen | Karte | Ja/Nein-Orakel mit drei Wahrscheinlichkeitsstufen |
| 3 | Dice Wheel (d4–d00 Set + Scatter Die) | Würfelrad (W4–W00 + Streuwürfel) | Vorschlag | Ergebnisse für W4, W6, W8, W10, W12, W20, W00 + W10, in der Mitte der Streuwürfel |
| 4 | Prompt Icons | Impuls-Symbole | Vorschlag | Zwei Bilder zur freien Deutung, oben eher positiv, unten eher negativ |
| 5 | Random Event Generator: Verb / Adjective / Noun | Zufallsereignis: Verb / Adjektiv / Substantiv | Vorschlag | Drei Schlüsselwörter |
| 6 | Sensory Snippets: Hear / See / Feel / Smell (Taste) | Sinneseindrücke: Hören / Sehen / Fühlen / Riechen (Schmecken) | Vorschlag | Vier kurze Beschreibungen, je eine pro Sinn |
| 7 | Map Icon | Kartensymbol | Vorschlag | Würfel/Hex in der Mitte mit zwei bis sechs Wegen; für Orts- oder Beziehungskarten |
| 8 | Names | Namen | Karte | Drei Vornamen (eher weiblich, eher männlich, neutral bzw. Genre-Name) |
| 9 | Traits: Virtue, Vice, Character Trait | Merkmale: Tugend, Laster, Charaktermerkmal | Karte (Überschrift) | Drei Zeilen: eine Tugend, ein Laster, ein sichtbares Merkmal |
| 10 | Card Number | Kartennummer | Vorschlag | 1–120 |
| 11 | Flavor Text | Flavortext (aufgeschnapptes Zitat) | Vorschlag | Ein Satz zur Stimmung |
| 12 | Situation: Catalyst, Location, Stakes | Situation: Auslöser, Ort, Einsatz | Karte (Überschrift) | Drei Zeilen: auslösendes Ereignis, Ort, was auf dem Spiel steht |
| 13 | Belongings | Besitz | Karte | Eine Kategorie und drei Beispiele (Fantasy, Modern, Sci-Fi) |
| 14 | Scene Types | Szenentypen | Vorschlag | Eine Zeile mit einer Szenenidee |

## Chancen (Likely Odds)

### Stufen

| Englisch | Deutsch | Wahrscheinlichkeit für „Ja“ |
|---|---|---|
| Bad | Gering | 25 % |
| Even | Mittel | 50 % |
| Good | Hoch | 75 % |

### Antworten

Von stark positiv bis stark negativ. Die betonten Antworten (mit „!“) gehen weiter als erwartet; die unsicheren (mit „?“) deuten auf Nachteile, Kosten oder Teilerfolge hin.

| Englisch | Deutsch |
|---|---|
| YES! | JA! |
| Yes | Ja |
| Yes? | Ja? |
| No? | Nein? |
| No | Nein |
| NO! | NEIN! |

## Begriffe aus der Spielanleitung

Begriffe für die Spielabläufe, die die App später nutzen kann.

| Englisch | Deutsch (Vorschlag) | Kurz erklärt |
|---|---|---|
| Answering Yes/No Questions | Ja/Nein-Fragen beantworten | Standard ist „Mittel“; „Gering“ und „Hoch“ für 25 % bzw. 75 % |
| Creating NPCs | NSC erschaffen | Merkmale, Besitz, Name; optional Einsatz als Motivation, Sinneseindrücke für Details |
| Reaction Roll | Reaktionswurf | Über den Schwierigkeitsgenerator: 1 Liebe auf den ersten Blick, 5–6 neutral, 10 Kampf bis zum Tod |
| Creating Random Events | Zufallsereignis erschaffen | Verb + Substantiv, bei Bedarf Adjektiv dazu |
| Creating Story Seeds | Abenteueraufhänger erschaffen | Drei Karten, aus den Situationen je Auslöser, Ort und Einsatz wählen |
| The Little Engine | Die kleine Engine | NSCs und Begegnungen spontan mit Schwierigkeit und Chancen führen |
| The Basic Loop | Die Grundschleife | Bei jeder Chancen-Ziehung auch die Schwierigkeit ansehen; liegt sie unter der Spannung, passiert ein Zufallsereignis |
| Tension | Spannung | Schwellenwert für Zufallsereignisse |
| Tension: static number | Spannung: fester Wert | Pro Szene festgelegt |
| Tension: scene-by-scene build | Spannung: steigt pro Szene | Beginnt bei 1, steigt mit jeder Szene, fällt nach mehreren Ereignissen zurück |
| Tension: draw-by-draw build | Spannung: steigt pro Ziehung | Beginnt bei 1, +1 pro Ziehung ohne Ereignis, zurück auf 1 nach einem Ereignis |
| Wrapping up a plot | Eine Handlung abschließen | „Und was ist noch los?“: Ereignis oder Situation ziehen |
